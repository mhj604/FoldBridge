# Watch 0.4.6 / Android 0.5.1 — 한쪽 새로고침과 알림 위치 조정

- Watch **0.4.6 / build 17**
- Android **0.5.1-local / versionCode 11**

워치 알림의 작은 원본 앱 아이콘과 모든 글씨를 0.4.5보다 **3pt 아래로** 옮겼습니다. 아이콘 크기·글자 크기·줄 간격은 유지합니다.

이제 **갤럭시나 워치 한쪽에서만 ‘연결 새로고침’**을 누릅니다. 폰은 BLE 서비스를 통째로 다시 만들던 동작을 바꿔, 보안 연결을 통해 워치에 재연결을 요청하고 기존 GATT 서비스를 유지합니다. 워치는 서비스 변경과 멈춘 연결·인증·응답 상태도 자동으로 복구합니다. 자세한 동작은 [프로토콜](https://github.com/mhj604/FoldBridge/blob/local-ble/docs/PROTOCOL.md)에 기록했습니다.

기존 서명 키와 동일한 Bundle ID/Android 패키지로 양쪽을 업데이트하세요. 재등록과 앱 삭제는 필요하지 않습니다. 등록 키·미전달 알림·필터를 유지합니다. 워치 강제 종료, Bluetooth 꺼짐, OS의 실행 중단까지 해제하는 기능은 아닙니다.

## 실제 기기에서 확인한 동작

Galaxy Z Fold7과 Apple Watch Ultra 2 / watchOS 27.0.1에서 양방향으로 확인했습니다.

| 조작 | 상대 기기 조작 | 확인 결과 |
| --- | --- | --- |
| 워치에서 새로고침 1회 | 폰 버튼 누르지 않음 | 양쪽 연결됨, 새 세션 생성, 미전달 대기열 0 |
| 폰에서 새로고침 1회 | 워치 버튼·앱 화면 조작 없음 | 워치의 원격 새로고침 수신 1회 증가, 양쪽 연결됨, 미전달 대기열 0 |
| 연결 후 유지 | 추가 새로고침 없음 | 암호화된 ping/pong 응답 왕복 확인 |

이 확인은 앱 실행 및 위치 연결 유지가 켜진 상태에서 진행했습니다. 강제 종료나 장기간의 범위 이탈 이후 모든 상황을 보장한다는 의미는 아닙니다. 실제 알림 내용과 기기 식별자는 공개하지 않습니다.
