# 서명 갱신 완료 알림

워치 0.5.29 / 빌드 63, Android 0.6.23-local / 코드 45.

예약 갱신이 성공한 것과 실행만 시도한 것을 구분하도록 완료 알림을 추가했습니다. Mac 갱신 도구가 실제 만료일 연장과 덮어 설치를 마친 뒤 `Documents/watchbridge-renewal.json` 영수증을 씁니다. 앱은 영수증 ID별로 워치 알림을 한 번 게시하고, 기존 암호화 Bluetooth로 폰에 전달합니다. 폰은 알림 게시를 수락한 뒤 확인 응답을 보내며, 워치는 이 응답을 저장해 재연결 때 중복 알림을 만들지 않습니다.

알림은 다음 만료일을 포함합니다. 폰이 떨어져 있거나 알림 권한이 꺼져 있으면 바로 뜨지 않습니다. 사용자 설정을 강제로 바꾸지 않습니다. 기존 주 1회 예약, 등록·설정·서명 키·설치 ID와 차량 버튼 설정은 유지합니다. 시스템 로그나 차량 제어를 사용하지 않습니다.

[예약·상태·사용 조건](AUTO_RENEW_KO.md). 알림 영수증은 앱 전용 컨테이너와 로컬 갱신 상태 폴더에만 저장합니다. 공개 저장소에 개인 Team·UDID·프로파일·상태 파일을 올리지 않습니다.
