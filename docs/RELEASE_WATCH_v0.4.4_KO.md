# FoldBridge Watch 0.4.4 — 상세 알림의 글씨 위치와 간격 조정

- Watch: **0.4.4 / build 15**
- Android: **0.5.0-local 유지**

펼친 상세 본문의 원본 앱 아이콘은 24pt로 유지합니다. 화면 좌우 기준 여백을 20pt에서 16pt로 줄여 텍스트를 넓히고, 문단 간격을 4pt에서 2pt로 줄였습니다. 추가 상하 여백도 제거해 제목과 본문이 더 위에서 시작하도록 조정했습니다.

시스템 글꼴과 글씨의 왼쪽 정렬, 장문 줄바꿈, watchOS의 스크롤·닫기 버튼을 사용합니다. 텍스트 줄 수와 높이는 고정하지 않습니다. 사진 첨부와 확장 프레임·중첩 스크롤은 추가하지 않습니다.

이번 변경은 기본 알림에 가깝게 상세 본문을 조정하는 범위입니다. 첫 요약 팝업과 상세 화면의 전체 디자인을 같게 만들거나, 모든 단계의 시스템 아이콘을 교체하는 기능은 포함하지 않습니다.

같은 Team과 Bundle ID로 워치 앱을 업데이트합니다. Android 앱을 다시 설치하거나 새 워치를 등록할 필요는 없습니다. 기존 알림을 재발송하지 않습니다.
