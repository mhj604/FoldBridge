# 갤럭시 마이현대 차량 제어

**한국어** · [English](VEHICLE_CONTROL_EN.md) · [전체 문서](README.md)

Android **0.6.0-local / 코드 16**, Watch **0.5.0 / 빌드 24**부터 제공하는 공식 위젯 연결 기능입니다. 차량 제어는 FoldBridge 워치 앱에서 시작합니다. 기존 애플워치 마이현대 버튼의 아이폰 연결 대상을 바꾸는 기능은 아닙니다.

## 동작 경로

`워치 FoldBridge → 기존 암호화 BLE → 갤럭시 FoldBridge → 공식 마이현대 위젯 버튼`

갤럭시의 한국 마이현대 앱(`com.hyundai.oneapp.kr`)이 제공하는 위젯을 Android AppWidgetHost로 연결합니다. 사용자가 위젯 추가를 허용하고 워치에 표시할 버튼을 선택해야 합니다. FoldBridge는 마이현대 계정 비밀번호·차량 PIN을 저장하거나 비공개 차량 API를 호출하지 않습니다.

워치와 갤럭시 사이에는 서버나 아이폰 중계가 필요하지 않습니다. **실제 원격 차량 제어에는 갤럭시 마이현대와 차량의 인터넷 연결 및 해당 서비스 이용 조건이 필요합니다.** 알림의 오프라인 BLE 전달과 차량의 원격 서비스는 별개입니다.

## 최초 설정

1. 두 앱을 위 버전 이상으로 업데이트하고 기존 BLE 연결을 유지합니다. 다시 등록할 필요는 없습니다.
2. 갤럭시 공식 마이현대에서 로그인과 차량 등록을 마칩니다.
3. 갤럭시 FoldBridge Local → **차량 제어 설정 → 마이현대 위젯 연결**을 엽니다.
4. 원하는 공식 제어 위젯을 선택하고 Android의 위젯 추가를 허용합니다. 마이현대 설정 화면이 나오면 차량·인증 설정을 완료합니다.
5. **워치에 표시할 버튼** 목록에서 사용할 항목을 선택합니다. 공식 위젯 안의 제어 버튼을 누르는 것은 목록 선택과 별개이며 실제 명령을 실행할 수 있습니다.
6. 워치 **FoldBridge → 차량 제어**를 엽니다. 갤럭시에서 선택한 공식 버튼 이름이 표시됩니다. 목록이 바뀌면 **제어 목록 새로고침**을 사용합니다.

워치 차량 제어 스위치를 끄면 목록과 실행을 중지합니다. **차량 제어 연결 해제**는 FoldBridge에 연결한 위젯과 버튼 선택만 제거합니다. 마이현대 계정이나 BLE 등록은 삭제하지 않습니다.

## 명령과 결과

워치에서 버튼을 선택하고 실행하면 해당 공식 위젯 버튼을 한 번 호출합니다. **‘마이현대 위젯에 전달했습니다’는 위젯 호출 응답이며 차량 제어 성공 응답이 아닙니다.** 실제 결과는 마이현대가 표시하는 화면·알림을 따릅니다. 알림 접근과 전달 설정이 되어 있으면 그 알림도 기존 경로로 워치에 전달될 수 있습니다.

마이현대가 휴대폰 잠금 해제·로그인·추가 인증을 요구하면 갤럭시에서 완료해야 합니다. 위젯의 실행 방식과 Android의 백그라운드 화면 실행 조건에 따라 휴대폰 조작이 필요할 수 있습니다. 모든 명령의 무인·백그라운드 실행을 보장하지 않습니다.

BLE 응답이 끊기거나 30초 동안 오지 않아도 차량 명령을 자동 재전송하지 않습니다. 동일 요청 ID는 중복 실행하지 않으며 최근 64개 ID를 기기에 보관합니다. 위젯이나 버튼 목록이 바뀌면 이전 목록의 명령을 거부하고 새 목록을 요청합니다.

## 목록이 없을 때

- **차량 제어 꺼짐:** 갤럭시 설정의 워치 차량 제어를 켭니다.
- **위젯 연결 필요:** 공식 마이현대 위젯을 추가합니다.
- **인증 설정 필요 / 버튼 없음:** 위젯의 차량·로그인 설정을 완료합니다. 버튼에 인식 가능한 이름이 없거나 해당 버전이 다른 구조를 사용하면 지원되지 않을 수 있습니다.
- **버튼 선택 필요:** 갤럭시의 체크 목록에서 항목을 고릅니다.
- **목록 변경:** 워치의 제어 목록을 새로고침합니다.

실제 차량 명령을 실행하는 자동 테스트는 포함하지 않았습니다. 현재 구현은 공식 위젯 연결 경로를 제공하며, 특정 차량 명령의 성공이나 모든 마이현대 버전과의 호환성을 확인한 결과로 제시하지 않습니다.
