# 갤럭시 마이현대 차량 제어

**한국어** · [English](VEHICLE_CONTROL_EN.md) · [전체 문서](README.md)

Android **0.6.0-local / 코드 16**, Watch **0.5.0 / 빌드 24**부터 제공하는 공식 위젯 연결 기능입니다. 차량 제어는 FoldBridge 워치 앱에서 시작합니다. 기존 애플워치 마이현대 버튼의 아이폰 연결 대상을 바꾸는 기능은 아닙니다.

## 동작 경로

`워치 FoldBridge → 기존 암호화 BLE → 갤럭시 FoldBridge → 공식 마이현대 위젯 버튼`

갤럭시의 한국 마이현대 앱(`com.hyundai.oneapp.kr`)이 제공하는 위젯을 Android AppWidgetHost로 연결합니다. 사용자가 위젯 추가를 허용하고 워치에 표시할 버튼을 선택해야 합니다. FoldBridge는 마이현대 계정 비밀번호·차량 PIN을 저장하거나 비공개 차량 API를 호출하지 않습니다.

워치와 갤럭시 사이에는 서버나 아이폰 중계가 필요하지 않습니다. **실제 원격 차량 제어에는 갤럭시 마이현대와 차량의 인터넷 연결 및 해당 서비스 이용 조건이 필요합니다.** 알림의 오프라인 BLE 전달과 차량의 원격 서비스는 별개입니다.

## 최초 설정

1. 두 앱을 위 버전 이상으로 업데이트하고 기존 BLE 연결을 유지합니다. 다시 등록할 필요는 없습니다.
2. 갤럭시 공식 마이현대에서 로그인과 차량 등록을 마칩니다.
3. 갤럭시 FoldBridge Local → **차량 제어 설정 → 마이현대 위젯 연결**을 엽니다.
4. 원하는 공식 제어 위젯을 선택하고 Android의 위젯 추가를 허용합니다. 마이현대 설정 화면이 나오면 차량·인증 설정을 완료합니다.
5. **워치에 표시할 버튼** 목록에서 사용할 항목을 선택합니다. 공식 위젯 안의 제어 버튼을 누르는 것은 목록 선택과 별개이며 실제 명령을 실행할 수 있습니다.
6. 워치 **FoldBridge → 차량 제어**를 엽니다. 갤럭시에서 선택한 공식 버튼 이름이 표시됩니다. 목록이 바뀌면 **제어 목록 새로고침**을 사용합니다.

워치 차량 제어 스위치를 끄면 목록과 실행을 중지합니다. **차량 제어 연결 해제**는 FoldBridge에 연결한 위젯과 버튼 선택만 제거합니다. 마이현대 계정이나 BLE 등록은 삭제하지 않습니다.

## 명령과 결과

워치에서 버튼을 선택하고 실행하면 해당 공식 위젯 버튼을 한 번 호출합니다. **‘마이현대 위젯에 전달했습니다’는 위젯 호출 응답이며 차량 제어 성공 응답이 아닙니다.** 실제 결과는 마이현대가 표시하는 화면·알림을 따릅니다. 알림 접근과 전달 설정이 되어 있으면 그 알림도 기존 경로로 워치에 전달될 수 있습니다.

마이현대가 휴대폰 잠금 해제·로그인·추가 인증을 요구하면 갤럭시에서 완료해야 합니다. 위젯의 실행 방식과 Android의 백그라운드 화면 실행 조건에 따라 휴대폰 조작이 필요할 수 있습니다. 모든 명령의 무인·백그라운드 실행을 보장하지 않습니다.

BLE 응답이 끊기거나 30초 동안 오지 않아도 차량 명령을 자동 재전송하지 않습니다. 동일 요청 ID는 중복 실행하지 않으며 최근 64개 ID를 기기에 보관합니다. 위젯이나 버튼 목록이 바뀌면 이전 목록의 명령을 거부하고 새 목록을 요청합니다.

## 목록이 없을 때

- **차량 제어 꺼짐:** 갤럭시 설정의 워치 차량 제어를 켭니다.
- **위젯 연결 필요:** 공식 마이현대 위젯을 추가합니다.
- **인증 요청:** 공식 위젯에 실제 로그인·인증 요청이 표시된 경우 갤럭시에서 완료합니다.
- **버튼 없음:** 결과 안내가 버튼을 가리는지 확인합니다. 빈 목록만으로 로그인 실패를 뜻하지 않습니다. 인식 가능한 이름이 없거나 위젯 구조가 달라진 경우에도 목록이 없을 수 있습니다.
- **버튼 선택 필요:** 갤럭시의 체크 목록에서 항목을 고릅니다.
- **목록 변경:** 워치의 제어 목록을 새로고침합니다.

실제 차량 명령을 실행하는 자동 테스트는 포함하지 않았습니다. 현재 구현은 공식 위젯 연결 경로를 제공하며, 특정 차량 명령의 성공이나 모든 마이현대 버전과의 호환성을 확인한 결과로 제시하지 않습니다.

## 하나의 차량 제어 위젯 (Watch 0.5.5 / 빌드 29)

스마트 스택과 시계 페이스에는 **차량 제어 위젯 하나**를 제공합니다. 위젯을 누르면 FoldBridge의 제어 창이 열리고, 그 안에서 **시동·정지·문 잠금·문 열기** 중 하나를 선택합니다. 위젯을 여는 것만으로 차량 명령을 실행하지 않습니다. 기존 위젯 종류는 유지하므로 이미 추가한 위젯도 새 형태로 갱신합니다. 이전 네 가지 버튼 추천·선택 설정은 더 이상 위젯에 표시하지 않습니다.

1. 스마트 스택을 열고 길게 누른 뒤 **+ → FoldBridge → 차량 제어**를 추가합니다. 시계 페이스는 **편집 → 컴플리케이션 → FoldBridge 차량 제어**를 선택합니다.
2. 위젯을 눌러 제어 창을 엽니다. 갤럭시 연결과 현재 제어 목록을 준비합니다.
3. 원하는 차량 버튼을 누릅니다. 기존 빠른 제어 지정은 유지합니다. 명확한 이름이 유일하게 일치하면 자동 지정하고, 지정이 필요하면 **빠른 제어 설정**에서 대응 항목을 선택합니다.

명령은 버튼 ID와 이름이 최신 목록과 일치할 때 한 번 전달합니다. 연결·목록을 15초 안에 받지 못한 요청은 취소하며, 나중에 지연 실행하지 않습니다. 응답이 없어도 차량 명령을 자동 반복하지 않습니다. 위젯 문구는 워치 시스템 언어, 제어 창은 FoldBridge의 언어 설정을 따릅니다.

## 이전 요청 안내로 버튼이 사라지는 경우 (Android 0.6.1 / Watch 0.5.3)

현재 권장 버전은 Android **0.6.1-local / 코드 17**, Watch **0.5.3 / 빌드 27**입니다. 최초 제어 후 공식 위젯에 “이전에 요청한 원격 서비스가 완료되지 않았습니다. 잠시 후 다시 실행해 주세요.” 안내와 **확인**만 남는 상태가 관찰되었습니다. 이때 버튼 목록은 비어 있지만 로그인이 풀렸다는 뜻은 아닙니다. 이 안내의 **확인**을 누르면 제어 버튼이 돌아왔습니다.

1. 워치 빠른 제어 또는 모든 차량 제어 화면에서 **안내 닫고 버튼 복구**를 누릅니다. 같은 기능은 갤럭시 차량 제어 설정에도 있습니다.
2. FoldBridge가 현재 공식 위젯의 해당 안내에 있는 확인 버튼을 한 번 호출합니다. 일반적인 차량 실행 확인창이나 인증창을 자동 처리하는 기능은 아닙니다.
3. 새 목록을 받은 뒤 원하는 차량 버튼을 다시 누릅니다. 안내 닫기는 이전 차량 명령을 반복하거나, 실패한 명령을 나중에 실행하지 않습니다.

복구 버튼은 위에서 관찰한 안내와 확인 버튼을 명확히 찾은 경우에만 표시됩니다. 다른 안내는 갤럭시 공식 위젯에서 내용을 확인합니다. **처리 중**이면 기다리고, 실제 **인증 요청**이면 갤럭시에서 완료합니다. 공식 위젯 호출 응답은 계속 실제 차량 성공과 구분합니다. 이 수정 과정에서 차량 명령을 실행하지 않았습니다.

## 안내를 닫아도 버튼을 선택하라고 나오는 경우 (Android 0.6.2 / Watch 0.5.4)

권장 버전은 Android **0.6.2-local / 코드 18**, Watch **0.5.4 / 빌드 28**입니다. 이전 버전은 공식 위젯의 내부 화면 번호를 버튼 식별자에 넣었습니다. 결과 안내에서 제어 화면으로 돌아올 때 이 번호가 바뀌면, 체크했던 버튼과 워치 빠른 제어 지정이 현재 버튼에 연결되지 않았습니다.

현재 버전은 같은 위젯의 유일한 정확한 버튼 이름을 기준으로 식별자를 유지합니다. 이전 선택 해시와 정확한 이름이 일치하면 등록을 이전하고, 워치에서도 같은 이름이 유일하면 기존 빠른 제어 지정을 이어갑니다. 새로 페어링할 필요는 없습니다. 이름이 달라졌거나 같은 이름이 여러 개면 갤럭시 체크 목록 및 워치 빠른 제어 설정에서 다시 지정합니다. 이 이전 작업은 차량을 조작하지 않습니다.

## 가까워졌을 때 자동 재연결 (Watch 0.5.5)

등록된 갤럭시에 연결 중일 때 필터링된 Bluetooth 검색을 즉시 함께 등록합니다. 범위를 벗어나 끊기면 시스템의 연결 대기를 유지하고, 다시 광고가 보이면 연결을 이어갑니다. 오래된 자동 재연결 플래그가 남아 있어도 휴대폰 광고가 다시 감지되면 연결 요청을 제출합니다. 연결 유지 모드의 위치 콜백과 타이머도 앱이 전면에 없을 때 끊긴 연결을 복구할 수 있습니다. 저장된 상대와 통신 오류가 난 경우에도 취소 콜백 뒤 재연결 요청을 남깁니다.

갤럭시의 FoldBridge Local 연결 서비스와 Bluetooth가 켜져 있어야 합니다. watchOS의 백그라운드 Bluetooth 실행 기회 제한, 사용자의 앱 강제 종료, 재부팅 직후 잠금 상태에는 OS 조건이 적용됩니다. 앱을 열지 않고 항상 즉시 연결됨을 보장하는 기능은 아닙니다. [Apple의 백그라운드 Bluetooth 설명](https://developer.apple.com/videos/play/wwdc2022/10135/)
