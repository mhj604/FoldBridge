## 알림 전달

갤럭시와 워치는 암호화된 Bluetooth LE로 직접 통신합니다. 알림 전달에 서버·인터넷·아이폰 중계는 필요하지 않습니다. 최초 워치 설정과 개발용 설치 절차는 별도입니다.

알림 제목·본문·원본 앱 아이콘을 전달하고, 워치에서는 알림 센터에서 읽습니다. 앱 안에 메시지 수신함을 따로 보관하지 않습니다. 원본 아이콘은 펼친 본문에 표시하며, 최초 요약 팝업의 시스템 앱 이름과 아이콘은 FoldBridge입니다. [표시 범위](NOTIFICATION_DISPLAY_LIMITS_KO.md)

충전율 변화로 반복되던 시스템 충전 알림은 기본 제외합니다. 처음 등록하거나 재연결할 때는 인증 완료 이후 게시된 새 알림부터 전달하고, 연결이 끊긴 동안의 알림을 몰아서 보내지 않습니다.

## 연결과 재연결

등록한 상대와 키는 유지합니다. 범위를 벗어난 뒤 다시 가까워지면 시스템 연결 대기와 서비스 필터 검색으로 재연결을 시도합니다. 연결 유지 모드의 콜백도 앱이 전면에 없을 때 끊긴 연결을 복구할 수 있습니다. 정상 연결에서 한쪽 기기의 새로고침은 기존 세션을 유지합니다.

갤럭시의 연결 서비스와 Bluetooth가 켜져 있어야 합니다. watchOS의 실행 예산·앱 강제 종료·재부팅 직후 잠금 상태에는 OS 조건이 적용됩니다. 모든 상황의 즉시 연결과 무제한 백그라운드 수신을 보장하지 않습니다. [연결 문제 해결](TROUBLESHOOTING_KO.md)

## 마이현대 차량 제어

동작 경로는 `워치 FoldBridge → BLE → 갤럭시 FoldBridge → 공식 마이현대 위젯`입니다. 원래 마이현대 워치 앱의 아이폰 경로를 바꾸지는 않습니다. 실제 원격 차량 서비스에는 갤럭시 마이현대와 차량의 인터넷 연결이 필요합니다.

스마트 스택이나 시계 페이스에는 **차량 제어 위젯 하나**를 추가합니다. 위젯을 누르면 제어 창이 열리고, 그 안에서 공식 갤럭시 위젯과 같은 네 항목을 선택합니다.

| 워치 항목 | 연결하는 공식 위젯 항목 |
| --- | --- |
| 시동/공조 켜기 | 시동/공조 켜기 |
| 문 잠금 | 문 잠금 |
| 비상등 켜기 | 비상등 켜기 |
| 문 잠금 해제 | 문 잠금 해제 |

공식 위젯에 없는 **정지 / 시동 끄기**는 제거했습니다. 버튼의 표시 이름과 실제 실행 대상이 일치하도록 연결합니다. 이전 정지 설정을 비상등에 넘겨 사용하지 않습니다. 내부 화면 번호가 바뀌어도 같은 위젯의 유일한 정확한 버튼 이름으로 지정을 유지합니다.

### 결과 안내와 실행 시간

1. 제어 버튼을 누르면 완료·승인·실패·미완료 등 결과 안내의 **확인·닫기**를 자동 처리합니다.
2. 안내 확인 응답과 최신 버튼 목록을 받으면 선택한 제어를 즉시 한 번 전달합니다. 고정된 몇 초 뒤에 실행하는 방식은 아닙니다.
3. 버튼 목록이 준비되지 않았으면 **1초 간격**으로 다시 요청합니다. 최초 입력부터 **15초** 안에 준비되지 않거나 화면을 닫으면 취소합니다.
4. 차량 명령 사이에는 **최소 3초 간격**을 적용합니다. 그 안에 들어온 요청은 ‘처리 중’ 응답이며 나중에 실행하도록 예약하지 않습니다.

위젯을 열기만 해서는 차량 명령을 보내지 않습니다. 실제 로그인·인증 요청은 갤럭시에서 처리합니다. 위젯 호출 응답은 차량 성공 응답과 구분하며, 실제 결과는 마이현대의 화면과 알림을 따릅니다. 응답이 끊긴 차량 명령을 자동 반복하지 않습니다. [차량 설정과 사용법](VEHICLE_CONTROL_KO.md)

## 언어와 서명

갤럭시와 워치 앱에서 한국어·English·시스템 언어를 각각 선택할 수 있습니다. 다른 앱의 알림 내용은 번역하지 않습니다.

무료 Apple 계정의 서명 갱신 문제는 차량 제어와 별개입니다. 기존 [자동 갱신 도구 안내](AUTO_RENEW_KO.md)에 동작 조건과 설치 방법을 기록했습니다. 이 배포에서 자동 갱신 일정은 변경하지 않았습니다.

## 변경 이력

[한국어 변경 이력](../CHANGELOG.md)에 알림 배치·원본 아이콘·재연결·위젯·결과 안내 자동 확인·공식 버튼 구성 수정 내용을 버전별로 기록했습니다. 과거 버전 안내는 당시 동작의 기록이며 현재 사용법은 이 문서와 최신 차량 제어 안내를 따릅니다.


Wattz(`dubrowgn.wattz`)와 브링앤티(`com.bring.bringnt`)는 같은 Android 알림 키가 유지되는 동안 최초 게시만 워치로 전달합니다. 전력·거리 등 수치나 본문이 바뀌어도 다시 전달하지 않으며, 워치에는 최초 내용이 남습니다. 폰에서 해당 알림이 제거된 뒤 새로 게시되면 다시 한 번 전달할 수 있습니다. 수집 서비스 재연결·새로고침 때 이미 떠 있는 알림은 기준 상태로만 등록하므로 다시 울리지 않습니다. 다른 앱의 알림 처리와 폰 자체 알림은 변경하지 않습니다.
