# 현재 버전과 남은 작업

[Android 0.6.20 연결/수신 대기 구분과 설치 결과](CONNECTION_STATE_0.6.20_KO.md). 워치 설치본은 0.5.26을 유지합니다.

**한국어** · [English](CURRENT_STATUS_EN.md) · [설치 순서](QUICK_START_KO.md) · [문서 목록](README.md)

기준일: **2026-11-18 KST**. 이 문서는 현재 소스·소유자 설치 기록·배포 파일을 구분합니다. 다른 사용자의 실제 설치 버전을 뜻하지는 않습니다. 버전별 조사 문서의 “현재”, “실패”, “완료”는 해당 문서 작성 당시의 결과입니다.

## 설치할 파일과 소스

| 항목 | 버전 / 받는 곳 |
| --- | --- |
| Android 앱 | **0.6.20-local / 코드 42** — [WatchBridge-0.6.20.apk](https://github.com/mhj604/WatchBridge/releases/download/android-v0.6.20/WatchBridge-0.6.20.apk) |
| 워치 앱·차량 위젯 | **0.5.26 / 빌드 60** — [local-ble 소스](https://github.com/mhj604/WatchBridge/tree/local-ble), `watch/FoldBridge.xcodeproj` |
| 앱 소스 | `main`, `local-ble`, `fix/watch-background-reconnect`에 반영. 문서 전용 커밋 뒤에도 앱 버전은 유지될 수 있습니다. |
| APK 배포 태그 | `android-v0.6.20` — 태그는 묶음 이름이며 포함된 Android 앱 버전은 0.6.20입니다. 워치 0.5.26을 뜻하지 않습니다. |
| 소유자 워치 설치 소스 | `95577b5` — 빌드 60 설치·비활성 실행 요청 완료. 이후 문서 커밋은 앱 동작을 바꾸지 않습니다. |

워치는 자신의 Apple Team·기기에 맞게 소스를 서명해 설치합니다. 공용 워치 설치 파일을 제공하는 방식이 아닙니다. **기존 사용자는 APK를 삭제하지 않고 업데이트하고, 워치 Bundle ID·Team과 Android 서명 키를 유지합니다.** 표시 이름은 WatchBridge지만 `dev.foldbridge.*`, 소스 경로, BLE UUID와 저장 키는 기존 등록 보존을 위해 유지합니다.

## 현재 동작과 관측 범위

- 알림 전달은 갤럭시–워치 BLE 직결입니다. 서버·아이폰 중계가 필요하지 않습니다. 차량 서비스에는 갤럭시 인터넷과 공식 마이현대 인증이 별도로 필요합니다.
- 재연결 인증 이전 알림은 나중에 몰아서 보내지 않습니다. 워치 앱에 메시지 수신함을 보관하지 않습니다.
- Wattz·브링앤티의 같은 알림 키 갱신은 반복 전달하지 않습니다. SystemUI 배터리 보호·충전 제한 안내도 워치 전달에서 제외합니다. 폰 원본 알림을 삭제하는 기능은 아닙니다.
- 잠금·실제 백그라운드에서 읽기 수신·표시 요청·폰 수신 확인이 기록됐습니다. 11월 18일 사용자는 실제 거리 복귀 후 앱 화면이 나타나지 않은 채 자동 연결됐다고 보고했습니다. 해당 복귀의 암호 잠금 여부는 명시되지 않았습니다.
- 이 관측을 수시간 잠금·모든 거리 복귀·프로세스 종료 후 복구의 완전 해결로 확대하지 않습니다. 빌드 60은 화면 기록 보완이며 연결 기능 수정은 없습니다.

## 우선순위와 미완료 항목

| 항목 | 현재 상태 / 다음 방향 |
| --- | --- |
| 문서 버전 혼선 | 현재 안내는 이 문서를 기준으로 통일하고 과거 기록을 분리합니다. |
| 연결 유지·복구 | **진행 대상.** 가까운 상태의 반복 종료·복구 지연, 수시간/밤새 잠금, 반복적인 실제 거리 이탈·복귀, OS가 프로세스를 종료한 뒤 복원은 완료로 표시하지 않습니다. 기존 등록을 유지합니다. |
| 무료 서명 자동 갱신 | **진행 대상.** Mac 주간 예약 구성과 워치 단독 갱신은 다릅니다. 워치 인터넷만으로 무료 갱신·적용하는 사용 가능한 경로는 아직 확보하지 못했습니다. [갱신 조건](AUTO_RENEW_KO.md). |
| 메인 화면 자동 표시 | **사용자 요청으로 보류.** 실사용 증상이 모인 뒤 앱 자체 화면 기록으로 이어갑니다. 위치 활동이 원인이라는 추정은 미확정입니다. [빌드 60 기록](DISPLAY_INVESTIGATION_0.5.26_KO.md). |

“연결 중지”를 누르면 폰 서비스가 꺼져 자동 연결 대상이 아닙니다. 다시 사용하려면 **워치 연결**을 누릅니다. 서비스가 켜져 있을 때의 **연결 새로고침**은 저장된 등록으로 복구를 요청합니다. **등록 해제는 일반 복구 절차가 아닙니다.** 설치 후 위치 세션의 최초 준비가 필요한 경우와 평소 재연결을 구분합니다.

조사에는 REA와 앱 자체 기록을 사용합니다. 시스템 로그·관리자 암호·실제 차량 명령·등록 초기화는 사용하지 않습니다. 기록 파일을 공개 저장소에 올리지 않습니다.
