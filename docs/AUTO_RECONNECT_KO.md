# 자동 재연결과 남은 조건

0.5.28에서는 복구 취소를 실패·종료 콜백 양쪽에서 처리하고, 휴대폰 광고를 실제로 발견한 복구 요청만 재설정합니다. [변경과 설치 결과](RANGE_RECOVERY_0.5.28_KO.md).

**한국어** · [English](AUTO_RECONNECT_EN.md) · [현재 버전·다운로드](CURRENT_STATUS_KO.md)

2026-11-18 기준 Android **0.6.20 / 42**, Watch **0.5.28 / 62**. 이전 버전의 결과는 아래 변경 기록으로 분리합니다.

## 현재 동작

1. 기존 등록을 사용합니다. 폰 서비스가 꺼져 있으면 **워치 연결**, 켜져 있으면 **연결 새로고침**을 사용합니다. **지금 동기화**는 이미 인증된 연결에서 대기 중인 전송을 처리합니다.
2. 정상 연결의 새로고침은 암호화된 갱신 요청을 보내 세션을 유지합니다. 단절 뒤에는 저장된 상대를 다시 인증하며 이전 알림 대기열은 비웁니다.
3. 워치는 Core Bluetooth 저장 기기 연결·복원과 거리 이탈 뒤 서비스 필터 복구 검색을 사용합니다. 응답 없는 네이티브 연결 대기를 다시 제출하는 경로가 있습니다.
4. 위치 연결 유지가 실제 실행 기회를 제공하고 양쪽이 지원하면 알림을 암호화된 읽기 경로로 수신합니다. 주기적 읽기 자체가 정지된 앱을 깨우는 것은 아닙니다.
5. 폰 **설정 → 연결 중지**는 의도적으로 서비스를 멈춥니다. 이 상태는 자동 복구 대상이 아니며 **워치 연결**로 시작합니다. 등록을 지우지 않습니다.

## 완료로 볼 수 있는 범위

잠금·실제 백그라운드에서 인증과 읽기 수신·표시 요청·폰 수신 확인이 기록됐습니다. 11월 18일 소유자는 거리 복귀 후 워치 앱이 보이지 않은 채 자동 연결됐다고 보고했습니다. 해당 복귀의 잠금 여부는 명시되지 않았습니다.

**수시간/밤새 잠금, 반복적인 실제 거리 이탈·복귀, OS 프로세스 종료 뒤 복원, 가까이 있는 동안의 반복 종료와 복구 지연은 아직 완료로 표시하지 않습니다.** 자동 복구를 위해 등록을 삭제하거나 정상 세션을 반복 취소하지 않습니다.

설치/프로세스 교체 후 위치 세션 최초 준비가 필요한 경우와 평소 재연결을 구분합니다. 메인 화면 자동 표시 문제는 사용자 요청으로 보류하고 현재 연결 코드는 유지합니다.
