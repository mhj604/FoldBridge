# FoldBridge Watch 0.4.2 — 큰 아이콘 이미지 첨부 제거

- Watch: **0.4.2 / build 13**
- Android: **0.5.0-local 유지**

## 수정 내용

0.4.1에서 원본 앱 아이콘을 사진 첨부로 전달한 결과, 시스템이 팝업에서 크게 표시하거나 알림 단계별 썸네일로 재사용하는 문제가 보고됐습니다. 이미지 첨부 생성·파일 복사·첨부 재요청 경로를 제거했습니다.

처음 뜨는 화면, 알림 센터 카드와 상세 화면 모두 기본 시스템 알림을 사용합니다. 기본 레이아웃에서는 원본 앱 그림을 별도로 표시하지 않으며 시스템 아이콘은 FoldBridge로 유지됩니다. 원본 앱 이름·제목·본문은 전달합니다. 그룹과 개별 카드의 시스템 아이콘을 서로 다른 Android 앱 그림으로 지정하는 공개 API는 제공되지 않습니다.

이미 받은 알림은 시스템에 보관된 옛 첨부가 남습니다. 기존 알림을 삭제하거나 다시 울리지 않으며 새로 수신하는 알림부터 첨부 제거가 적용됩니다. 등록 키·대기 알림·언어·BLE 통신은 유지합니다.

## 설치

[local-ble 브랜치](https://github.com/mhj604/FoldBridge/tree/local-ble) 또는 소스 ZIP에서 Xcode 프로젝트를 열고 기존 Team/Bundle ID로 워치 앱을 업데이트합니다. Android APK는 이전 0.5.0과 같은 파일입니다.
