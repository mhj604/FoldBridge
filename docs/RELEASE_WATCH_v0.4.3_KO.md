# FoldBridge Watch 0.4.3 — 상세 본문의 작은 원본 아이콘

- Watch: **0.4.3 / build 14**
- Android: **0.5.0-local 유지**

원본 앱 아이콘을 유지하는 방식을 적용했습니다. 첫 팝업과 알림 센터 카드의 시스템 아이콘은 FoldBridge이며, **눌러 펼친 본문에만 원본 앱 아이콘을 24pt**로 표시합니다.

큰 미리보기와 썸네일 재사용을 만들었던 사진 첨부는 사용하지 않습니다. 아이콘이 있는 상세 본문만 화면별 유한 폭으로 배치하고, 텍스트 줄 수·높이는 고정하지 않습니다. 아이콘이 없으면 시스템 기본 텍스트 화면을 사용합니다.

기존 알림을 삭제/재발송하거나 카테고리를 바꾸지 않습니다. 이 표시 방식은 업데이트 후 새로 받는 알림에 적용합니다. 등록·대기열·언어 선택은 유지합니다.

[local-ble 브랜치](https://github.com/mhj604/FoldBridge/tree/local-ble) 또는 소스 ZIP에서 Xcode 프로젝트를 열고 기존 Team/Bundle ID로 워치 앱을 업데이트합니다. Android APK는 이전 0.5.0과 같은 파일입니다.
