# 연결 새로고침과 문제 해결

## 연결이 끊겼거나 ‘인증 시간이 만료됐습니다’가 나옵니다

1. 두 기기의 Bluetooth를 켜고 가까이 둡니다. 워치 잠금을 풀고 FoldBridge를 엽니다.
2. 갤럭시 연결 카드의 **연결 새로고침**을 누릅니다. 오래된 BLE 서버·구독·인증 세션을 정리하고 새 연결 대기를 시작합니다.
3. 워치 메인의 **연결 새로고침**을 누릅니다. 기존 연결을 취소한 뒤 갤럭시를 다시 검색하고, 저장된 상대 키로 새 인증을 진행합니다.
4. 연결됨이 되면 필요할 때 **지금 동기화**를 누릅니다.

새로고침은 등록 키와 휴대폰 미전달 알림을 지우지 않습니다. 짧은 간격으로 여러 번 누르는 요청은 줄입니다. 처음 등록한 적이 없다면 [최초 등록 순서](QUICK_START_KO.md#5-처음-한-번-등록)를 따릅니다.

등록된 상대와 보안 키가 다르다는 오류는 단순 만료와 다릅니다. 앱을 삭제했거나 다른 키/기기로 바꿨는지 확인하고, 그 경우에만 양쪽 등록을 해제한 뒤 새로 등록합니다.

## 연결됨인데 알림이 없습니다

- Galaxy의 일반 알림 권한과 **다른 앱의 알림 접근**은 별개입니다. **설정 → 알림 접근 설정 → FoldBridge Local 알림 전달**을 허용합니다.
- 전달 앱 선택과 **모든 앱 알림**, 워치 알림 허용·집중 모드를 확인합니다.
- Galaxy의 진단에서 수집/전달/수신 확인을 구분해 볼 수 있습니다. 워치 설정에도 수신·알림 등록 개수가 있습니다. 수신 확인은 watchOS 표시 요청 수락이며 사용자가 읽었다는 의미는 아닙니다.
- 워치가 앱을 중단했으면 FoldBridge를 직접 열고 동기화합니다. 위치 연결 유지도 OS 제한을 없애지는 않습니다.

## ‘민감한 알림’으로 본문이 가려집니다

Android가 알림 수집 서비스에 가린 내용을 전달한 경우입니다. 본문 전체 전달을 원하는 사용자는 [앱별 민감한 알림 허용](BUILD_AND_SETUP.md#민감한-알림-본문-허용)을 설정할 수 있습니다. 워치의 ‘전체 알림을 보려면 탭하기’는 별도 시스템 설정입니다.

## 충전할 때 같은 시스템 알림이 반복됩니다

Galaxy 앱의 **충전 상태 알림**을 끕니다. 충전율 변경마다 갱신되는 Samsung System UI 알림은 기본으로 제외합니다. 일반 앱의 알림은 이 설정으로 제외하지 않습니다.

## 원본 앱 아이콘이나 FoldBridge 아이콘이 이상합니다

원본 앱 아이콘은 펼친 알림 본문에 표시됩니다. 처음 뜨는 시스템 아이콘과 상단 앱 이름은 FoldBridge입니다. 원본 아이콘이 없으면 기본 앱 심벌을 표시합니다.

FoldBridge 0.3.0 워치 빌드는 도형의 밝기·면적에 따른 시각적 중심으로 앱 아이콘을 다시 생성하고 아이콘 리소스 이름도 변경했습니다. 오래된 시스템 아이콘이 남아 보이면 앱 목록에서 다시 열어 보고 워치를 재시작합니다. 아이콘 갱신만을 위해 앱을 삭제할 필요는 없습니다.

## 다른 사람의 워치에 다운로드한 앱을 설치할 수 없습니다

Apple 개발용 서명은 자신의 Team·Bundle ID·기기 등록으로 준비해야 합니다. 이 저장소는 Android APK와 워치 소스를 배포합니다. 다른 사람의 워치에 쓸 수 있는 Apple 서명 프로파일은 포함하지 않습니다.

## 알림 센터 카드는 정상인데, 눌러 펼치면 레이아웃이 깨집니다

워치 0.4.1 / 빌드 12부터 사용자 정의 알림 scene을 제거하고 초기 버전처럼 시스템 기본 상세 화면을 사용합니다. 원본 아이콘은 직접 그린 헤더 대신 표준 이미지 첨부로 표시합니다. 제목/본문 줄바꿈과 스크롤을 앱의 수동 여백으로 조정하지 않습니다.

이전 알림을 삭제하거나 재등록하지 않고 유지합니다. 설치 전에 열어 둔 상세 화면이 있다면 닫았다가 다시 여세요. 이미 저장된 이전 알림에는 새 이미지 첨부가 없을 수 있지만 텍스트는 기본 알림 화면으로 표시됩니다.

## 앱 아이콘이 팝업에서 사진처럼 커지거나 그룹/개별 카드에 재사용됩니다

0.4.1에서 앱 아이콘을 표준 이미지 첨부로 넘긴 결과, 시스템이 이를 아이콘이 아닌 미디어 미리보기/썸네일로 처리했다. 0.4.2부터 아이콘을 알림 첨부로 보내지 않는다. PNG 원본의 크기만 줄이는 것으로는 시스템 미디어 영역의 표시 크기를 제한할 수 없다.

watchOS 기본 알림의 앱 아이콘은 알림을 등록한 FoldBridge다. 그룹과 개별 카드의 시스템 아이콘을 각각 Android 앱 아이콘으로 지정하는 공개 설정은 없다. 기본 시스템 아이콘과 별개로 표시하는 원본 앱 그림을 구분해야 한다.

이미 도착한 0.4.1 알림은 시스템이 보관한 첨부 이미지가 남아 있다. 업데이트가 기존 알림을 삭제하거나 재발송하지 않으므로 첨부 제거는 새로 전달되는 알림에 적용된다.

## 작은 원본 아이콘 표시를 선택한 경우 (0.4.3)

첫 팝업과 알림 센터 카드에는 FoldBridge 시스템 아이콘이 나오는 것이 정상이다. 새 알림을 눌러 펼친 본문 오른쪽에만 원본 아이콘이 24pt로 표시된다. 사진 첨부가 아니므로 전체 크기 미디어나 카드 썸네일로 표시하지 않는다. 원본 이미지가 없으면 기본 텍스트 화면을 사용한다.

이전 버전으로 받은 알림의 카테고리와 첨부는 소급해 바꾸지 않는다. 기존 알림을 삭제/재발송하지 않으므로 새 아이콘 표시 방식은 업데이트 후 새로 받는 알림에 적용한다.
