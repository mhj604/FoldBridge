# Android 0.6.22 — 연결 상태 불일치·새로고침 복구

**한국어** · [English](CONNECTION_RESYNC_0.6.22_EN.md) · [현재 상태](CURRENT_STATUS_KO.md)

2026-11-20 KST. Android **0.6.22-local / 코드 44**. 워치 **0.5.28 / 빌드 62**와 저장된 등록·설정·키·UUID는 유지합니다.

## 관측과 원인 범위

사용자는 워치는 연결로 보이지만 폰은 등록된 워치 연결 대기이며 새로고침으로 풀리지 않는다고 보고했습니다. REA로 파일을 확보한 시점에는 워치 내부도 이미 인증 실패 후 재시도 중이었으므로 최초 화면 불일치를 양쪽 동시 표본으로 확보했다고 표현하지 않습니다.

- 폰 빌드 43은 실행·광고 중이지만 선택된 상대와 인증은 없었습니다. 공유 LE 연결 콜백 36회, 새로고침 3회에 비해 자체 서비스 구독·저장 상대 인증 요청·거부된 쓰기는 모두 0이었습니다.
- 워치 빌드 62는 물리 연결이 남아 있으나 인증 완료가 0회였고, 빠른 인증 약 1만4천 회와 서비스 대기를 반복했습니다. 이벤트에는 서비스/특성 발견 성공 → 인증 쓰기 → 서비스 대기가 약 1초 주기로 남았습니다.
- 조사 중 폰 앱 프로세스를 한 번 임시 재시작하자 같은 등록·같은 워치 프로세스에서 인증·읽기가 복원됐습니다. 이는 수정 전 임시 복구이며, 앱을 다시 시작하면 해결됐다는 관측을 코드 수정의 성공으로 계산하지 않습니다.

이 조합은 폰의 앱 GATT 서비스까지 요청이 전달되지 않던 상태와 일치합니다. 정확한 OS 내부 사유·쓰기 오류 코드는 기존 워치 기록만으로 확정하지 못했습니다. 등록 키 손실이나 물리 거리 문제로 단정하지 않습니다.

## 코드 수정

자동 복구도 추가했습니다. 저장된 상대와 공유 LE 연결 관측은 있지만 인증된/인증 중 상대가 없고 앱 ATT 요청이 90초 이상 없으면 자체 GATT 서버를 다시 엽니다. 반복 간격은 180·360·720초로 늘립니다. 공유 LE 관측을 상대 인증 증거로 취급하지 않으며, 정상 인증 연결·최근 요청·연결 관측도 없는 단순 대기는 이 경로로 건드리지 않습니다. 기존 폰 유지 작업에서 검사하므로 90초가 OS 스케줄 지연을 포함한 연결 완료 보장 시간은 아닙니다.

1. **인증된 연결이 없는 폰 새로고침:** 광고만 끄고 켜던 경로에서 WatchBridge 자체 GATT 서버를 닫고 다시 엽니다. 전체 앱 종료·연결 중지 버튼·등록 해제가 필요하지 않습니다. 정상 인증 연결에는 기존 암호화된 새로고침을 유지합니다.
2. **읽기 우선 인증 중 새로고침:** 최근 15초 이내의 인증 응답은 보존해 진행 중 교환을 지우지 않습니다. 오래 방치된 응답은 이 예외로 무한 보존하지 않습니다.
3. **폰 세션 소실 안내:** 저장된 상대가 있지만 폰 인증은 사라진 상황에서 워치가 PULL을 읽으면, ATT 오류만 되풀이하는 대신 기존 공개 `wake`/v1 프레임으로 새 인증을 요청할 수 있습니다. 기존 워치 코드를 사용하며 새 난수·저장된 키 검증·암호화 confirm/ready를 거쳐야 합니다. 이 안내는 알림·차량 데이터나 연결 완료 권한을 제공하지 않습니다.
4. 앱 자체 상태에 `refreshGattReopens`, `automaticGattReopens`, `reauthenticationHints`, `observedGattLinks`, `gattRequestIdleMillis`를 추가해 해당 복구 경로의 실행과 요청 공백을 구분합니다.

## 적용과 한계

기존 Android 서명 키·앱 ID로 덮어 설치했습니다. 설치 후 폰은 빌드 44·인증·정상 읽기, 워치는 기존 빌드 62·인증·읽기 수신이 기록됐습니다. 워치 앱 실행 명령이나 등록 해제는 하지 않았습니다.

자동 복구까지 포함한 최종 APK도 덮어 설치했습니다. 최종 폰 표본은 빌드 44·인증·수신 정상·새로고침 0회였고 `automaticGattReopens`, `refreshGattReopens`, `reauthenticationHints`는 모두 0이었습니다. 워치도 기존 빌드 62·인증·읽기 정상입니다. **새 자동/수동 GATT 재개방·읽기 안내 분기가 최초 고착 상태에서 실행돼 해결한 것까지 관측한 것은 아닙니다.** 최초 고착은 이미 임시 재시작으로 해소됐습니다. 수시간 잠금·반복 거리 이동 시험은 추가 수행하지 않았습니다.
