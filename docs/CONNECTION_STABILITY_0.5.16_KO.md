# 연결 유지 수정 — Android 0.6.12 / Watch 0.5.16

[English](CONNECTION_STABILITY_0.5.16_EN.md) · [문서 목록](README.md)

2026-11-14 수정 후보입니다. Android는 코드 30, Watch와 차량 위젯은 빌드 42입니다. 워치 설치·실행은 완료했고, Android APK는 빌드했으나 핫스팟의 ADB 연결이 열리지 않아 아직 해당 갤럭시에 설치하지 못했습니다. 기존 등록·키·차량 설정은 유지합니다.

## 변경한 동작

- Android의 15초 유지 관리와 새로고침에서, 어댑터 전체의 GATT 상태만 보고 현재 서버의 인증 세션을 지우던 경로를 제거합니다. 실제 GATT 서버 연결 종료 콜백을 사용합니다.
- Android의 30초 indication 대기와 Watch의 45초 쓰기 대기가 늦어졌다는 이유만으로 물리 링크를 취소하지 않습니다. 전송 완료 또는 실제 연결 종료 콜백을 기다리며, 대기 횟수를 앱 자체 상태에 기록합니다.
- Android 스택이 아직 받지 않은 전송에 BUSY를 반환하면 같은 조각을 재시도합니다. 이미 수락된 차량 명령을 타이머로 재전송하지 않습니다.
- 순서가 맞지 않거나 유효 시간이 지난 부분 메시지는 버리고, 그것만으로 연결을 끊지 않습니다. 완성된 메시지의 암호화·상대 인증 실패 처리는 유지합니다.
- Watch에서 이미 유지된 알림 구독을 전면에서도 다시 끄지 않습니다. 서비스·특성 탐색의 일시 오류는 같은 물리 링크에서 복구하고, 신뢰한 폰의 인증 지연도 가능한 경우 같은 링크에서 재개합니다.

위 항목은 코드에서 확인한 앱 자체 연결 종료 경로의 수정입니다. 실제 기기의 반복 종료 원인이 모두 이것이었다고 단정하거나, 무선·운영체제 수준의 단절이 없어졌다고 주장하지 않습니다.

## 폰의 상태 알림

실제로 상대가 있고 구독·인증이 완료됐을 때만 **워치 연결됨**으로 표시합니다. 그 전에는 조용한 **워치 연결 대기 중**으로 표시하고, 같은 상태를 반복 갱신해 울리지 않습니다.

연결 전 알림까지 완전히 숨기는 요구는 이번 구현에서 충족하지 않습니다. 현재 상시 BLE 서비스는 Android 전경 서비스이며 알림이 필요합니다. 이를 없애려고 서비스를 중지하면 자동 재연결도 중단됩니다. [Android 전경 서비스 문서](https://developer.android.com/develop/background-work/services/fgs/launch), [BLE 백그라운드 문서](https://developer.android.com/develop/connectivity/bluetooth/ble/background).

## 설치와 남은 작업

- Android와 Watch의 빌드·서명 완료. Watch 0.5.16은 덮어 설치하고 한 번 실행했습니다.
- Android 0.6.12는 공개 후보 APK로 제공합니다. 갤럭시가 핫스팟을 제공해 무선 디버깅 주소가 표시되지 않았으며, 현재 로컬 주소의 ADB 포트도 닫혀 있어 원격 설치가 남았습니다. APK를 직접 덮어 설치하거나 공통 Wi-Fi/USB에서 설치할 수 있습니다. 삭제 후 재설치는 필요하지 않습니다.
- 양쪽 수정본의 실제 지속 연결, 장시간 잠금, 거리 이탈·복귀의 최종 결과는 아직 확보하지 못했습니다. 시스템 로그 수집이나 차량 명령은 실행하지 않았습니다.
- 작업 종료 때는 등록을 유지하고 폰 설정의 **연결 중지**만 사용합니다. 원격 조작이 되지 않으면 이 마지막 조작은 사용자가 해야 합니다. ADB 연결 종료만으로 갤럭시–워치 연결이 종료됐다고 보지 않습니다.

## 최우선 서명 목표

Mac 없이 워치 인터넷만으로 무료 자동 갱신하는 경로는 계속 미완료입니다. Exa로 공개 소스를 추가 조사했으나 적용 가능한 native watchOS 자동 갱신 구현을 확보하지 못했습니다. [SideStore 설치 문서](https://docs.sidestore.io/docs/installation/install)는 iPhone/iPad/iPod touch를 대상으로 하며, [iLoader 자동 갱신 문서](https://github.com/AndreySemjonov/iloader/blob/main/docs/automatic-renewal.md)는 Watch 자동 갱신을 지원하지 않는다고 명시합니다. Apple은 무료 Personal Team 프로파일의 7일 유효기간을 설명합니다. [Apple 계정 안내](https://developer.apple.com/help/account/basics/about-your-developer-account/).

기존 주 1회 macOS 예약은 대안으로 유지합니다. 이는 워치 단독 갱신이 아닙니다. 새 Watch 설치본에 맞춰 로컬 만료 기록과 예약용 커밋 소스를 갱신하며, 예약 등록 시 즉시 갱신을 실행하지 않습니다. 개인 프로파일·기기 식별자·인증 자료는 공개 저장소에 포함하지 않습니다.
